The banner for outcomes and errors (Gestalt BannerSlim). One message, one primary action.

- Error: `error-weak` ground with `text-error`. One message for every refused login attempt, so the page cannot reveal who has an account.
- A second text action rides inside the message node (for example "Moved to Stopped. Add a reason. Undo"), because BannerSlim takes exactly one primary action.
- Used for failed writes in every popup.
