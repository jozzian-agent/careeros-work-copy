The header of the Job, Company and Experience detail pages: a back link with a brand-coloured arrow, the title, meta, and the Edit and Delete actions.

- Edit and Delete are both gray secondary buttons of the same weight. Delete carries a red element: its icon and label use `text-error`. It never takes a red fill here, so it cannot be mistaken for the page's primary action.
- The detail content column is 960px wide, shared by the three detail pages.
- The back-link arrow follows the brand token (Gestalt's own brand icon token is Pinterest red and is rebound).
