Gestalt Link. Black (`ink`), underlined, inheriting the size of the text around it. On hover the underline is removed. It does not turn blue or green.

- Navigation links in the header are 16px bold; footer links are 14px bold. The product uses the same black underlined link; every in-text link must keep its underline.
- Inline links inside paragraphs keep the paragraph's size and weight.
- Use `a` with a real `href`; actions that do not navigate are Buttons.
