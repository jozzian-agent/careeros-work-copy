The owner-action signal. "Needs your input" in `violet` text on `violet-wash` with a violet ring, 24px high, 12px bold.

- Violet is used for this signal only.
- It reads the payload's own `needs_attention`, the same value the filter bar's "Needs attention" chip counts, so the chip and the filter cannot disagree.
- On a board card it sits at the left of the 32px top row; the list view shows the Badge form instead.
- A job's detail page makes at most one ask of its owner.
