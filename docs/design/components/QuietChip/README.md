A chip that must never alarm. It states a machine state: extraction failed, details filling in, "Posting closed".

- `text-subtle` text, transparent or `fill-secondary` ground, a `border-decorative` border at most. Never a coloured badge type.
- The one exception is the warning closed-posting chip: `warning-weak` ground with an alert icon, reading "Closed N days ago". The payload decides which of the two shows, never the card's own date arithmetic.
- The ingest-failed indicator is a quiet chip with a "Try again" action beside it.
